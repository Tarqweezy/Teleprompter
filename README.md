# Teleprompter

Mobile web app (PWA) for recording 30 to 60 second videos with your script on screen. The script is not in the video.

## Put it on GitHub Pages

1. Create a public repo named `Teleprompter`.
2. Upload `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`, and this README.
3. Go to Settings > Pages. Set Source to "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. Open the link it gives you, for example `https://YOURUSERNAME.github.io/Teleprompter/`.

## Install on iPhone

1. Open the link in Safari (not Instagram, Facebook, or Chrome).
2. Tap the Share button, then "Add to Home Screen", then "Add".
3. Open it from the home screen. Allow camera and microphone when asked.

## Screens

- **Record:** full-screen camera with the script near the top of the screen. Red button starts and stops. Video saves through the iPhone share sheet.
- **Scripts:** add, edit, and delete scripts. Tap a script to put it on the camera.
